# ADR-0008：篮子就是数据目录里的一个文件

Accepted（2026-10-20）。取代 ADR-0001 里「篮子由 CLI 增删、状态存在 `baskets.json`」那部分，
以及 ADR-0003 里「CLI 是写入口」那部分。

## 背景

原来篮子存在一个 `baskets.json` 里，由 `cherry new` / `add` / `rm` 通过 local socket 改。
后果是：看不见（macOS 上还在 `~/Library/Application Support`）、改不了手写、没法单独备份，
而「删篮子 / 换 id / 吊销链接」这些操作一个都没有——它们全被同一个前提挡住了：id 是服务
内部生成的东西。

## 决定

**一、一个篮子 = `<数据目录>/<名字>.basket` 文件。** 数据目录是 `~/.config/cherryshare`
（跟着 `XDG_CONFIG_HOME`，不跟 `dirs::config_dir()` 走——macOS 上那是
`~/Library/Application Support`）。文件格式：

```
# 给老王看照片
id 3f2ae0c1d9b84f5a8c1d2e3f4a5b6c7d
~/Pictures/2026
/Volumes/外置盘/素材
```

一行一条要分享的路径，`~/` 开头或绝对路径（相对路径没有意义——服务的 cwd 是 `/`，报错带
行号）。路径里第一个 `.` 段把源和可见路径分开（ADR-0009）：后面的可见路径可以多段。
`#` 开头和空行忽略。`id <32 位十六进制>` 是凭证，最多一行。只认 `<名字>.basket`
且不以 `.` 开头的文件，编辑器留下的临时文件不会被当成篮子。

**二、文件是唯一真相。** 除了补一个缺失的 `id` 行，工具不往里面写任何东西。CLI 只剩
`status` / `list` / `show` 三个读命令。建篮子、加东西、拿走东西、吊销链接，全是改这个文件
（删文件就把 id 一起带走了）。

**三、补 id 写不回去就算读不进来。** 文件里没有 `id` 就发一个并插在开头那段注释之后。
拿一个只活在内存里的 id 去服务，重起之后链接会变——那比直接报「读不进来」更糟。

**四、热加载靠轮询 mtime。** 每个请求前 stat 数据目录和每个 `.basket`，变了就整份重读。
不用 inotify：几个 stat 比请求本身便宜，没有漏事件、FSEvents 合并这些边界要处理，而
「没人来问的时候热加载」本来没有意义。可见的差别只有一个：手写的文件要等你第一次
`cherry list`、或者别人来拉的时候才长出 `id` 行。

**五、读不进来的文件进错误表，不影响别的篮子。** 原因带行号，`cherry list` 里显示，
日志留一条。坏文件没有 id，所以别人的链接本来也指不到它。

**六、源没了不写回文件。** NFS 列目录和网页列目录本来就跳过死引用（ADR-0001），
`cherry list` 额外标一句「源不在了」。工具不替你改你写的文件。

**七、挂载点那段名字做投影，篮子名不做。** 篮子名就是文件名，改文件名就是改篮子名，
id 不变，旧链接照样能用。挂载点叶子只留字母数字和 `-` `_` `.`，其余（空格、引号、`$()`）
一律换成 `-`，所以对方要粘进 shell 的那行命令里一个引号都不用写。投影撞名（`a b` 和
`a-b`）靠后面那 8 位 id 分开。

## 为什么

- 手写、看得见、能 diff、能单独备份，跟 edhive 的 `.cell` 一个用法。
- `id` 落到文件里，顺手补上两个一直缺的操作：删文件 = 吊销，改那一行 = 换凭证。名字和
  凭证分开之后，改名不会意外换凭证。
- 篮子名 = 文件名，「重命名篮子」这个操作也就不需要了。
- 少一整套写命令、一个 JSON 状态文件和一个持久化写入路径。

## 代价

- **补 id 和编辑器会撞。** 编辑器整份保存把 `id` 行冲掉，服务会当成新篮子再发一个，旧链接
  静默失效——日志会明说「id 从 aaa 变成 bbb，旧链接不再有效」。规避办法：先 `cherry list`
  一次让 id 落进文件，之后改路径时把那行留着。不做「记住上一个 id」的补救，那要多一个状态
  文件，真相就又分家了。
- **数据目录换位置。** 启动时如果数据目录里一个 `.basket` 都没有，会把老的 `baskets.json`
  （新目录或老的 `dirs::data_dir()` 下）拆成文件，原文件改名成 `baskets.json.migrated`。
  socket 路径跟着换，装着的服务要重启一次。
- **按名字取单个篮子**原本是 `cherry show <名字>` 的事，它按文件名匹配，macOS 上组合
  字符（NFC/NFD）差异理论上会让「名字一样却说没有」。那个命令后来并进了 `cherry list`
  （ADR-0010），这条代价随之消失：不再按名字取，只是把所有文件全部列出来。
