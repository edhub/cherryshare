# ADR-0009：`/./` 保留可见目录

Accepted（2026-10-20）。取代 ADR-0001 里「篮子根是一排平的名字」那部分，扩展
ADR-0008 的行格式。

## 背景

原来一行一颗 cherry，名字取路径最后一段。后果是两个都叫 `dist` 的目录不能放进同一个
篮子，整个 `.basket` 文件读不进来。

edhive 的 `.cell` 里已经有一条现成的规则：路径中间的 `/./` 声明从哪个位置开始保留目录。
把同样的写法抄进 basket 文件时，它只是被当成普通路径段，篮子还是平的名字。

## 决定

**一、第一个 `.` 段把源路径和可见路径分开。**

```
[前缀/]./可见/路径
```

第一个精确等于 `.` 的路径段是分界：它后面那段（可能多段）是篮子里的**可见路径**，
源路径是「前缀 + 可见路径」。没有 `.` 段时还是老规矩，取最后一段当名字。

```
~/dev/mt6000/./edproxy/dist      → 可见 edproxy/dist，源 ~/dev/mt6000/edproxy/dist
~/dev/rust/./cherryshare/dist    → 可见 cherryshare/dist，源 ~/dev/rust/cherryshare/dist
```

可见路径的每一段都不能为空、不能是 `.` 或 `..`；可以带空格。以 `/` 或 `~` 开头的行才
认，相对路径照旧拒。

**二、可见路径是一棵树，中间层是虚拟目录。**

篮子根不再是「一排名字」，而是一棵由文件定义出来的树。可见路径正好是一颗 cherry 时，
它是一个真文件或真目录；路径中间没被点名的那几层是**虚拟目录**：

- 虚拟目录不对应磁盘上的目录，也不把源目录里没写的东西带出来。列它只列点名的子项。
- 可见路径正好是一颗真目录时，整个子树都共享（跟以前共享一个目录一样）。
- 两条可见路径不能重复，也不能一条是另一条的前缀（`agent` 和 `agent/APPEND_SYSTEM.md`
  不能同时出现）。否则分不清 `agent` 是整颗还是一层壳；报错会指出两行。
- 老篮子（全是一段可见路径）就是每个名字一颗 cherry，行为不变。

**三、虚拟目录的属性。**

mode 报 0755，size 报 0，mtime 用定义这个篮子的 `.basket` 文件的 mtime。结构只由这份
文件决定，源文件内容变化不影响目录的时间；客户端靠它决定要不要重取目录列表。

NFS、网页、zip、目录大小都从同一棵树算。`resolve` 落到虚拟目录时没有磁盘路径，调用方
按目录处理；写到磁盘之前仍是原来那套符号链接和越界检查。

**四、别名先不做。**

有了多段可见路径，别名的参照点不清楚：它指最后一段、整条可见路径、还是顶层那段？
先把可见路径的规则定死，等真有平路径重名需求时再单独定别名，而且只作用在平的行上，
不跟 `/./` 混。

**五、顶层 `_` 前缀仍然留给网页。**

可见路径第一段以 `_` 开头的，网页取不到，NFS 可以（ADR-0002）。`/./` 不改变这条。

## 为什么

- 两个 `dist` 用各自的前缀就能区分，不用拆成两个篮子、也不用换源目录名。
- 名字和磁盘路径解耦：源目录改名时只改那一行，对方看到的路径不变。
- 只点名要分享的东西，不把整个父目录一起带出去。

## 代价

- 列目录、路径解析、NFS 的 lookup/getattr、zip、目录大小五处都得认两种节点（虚拟目录
  和磁盘路径），代码路径变多。
- 可见路径之间不能重叠，手写时要多想一步；错误里会指出冲突的两行。
- 虚拟目录的 mtime 是篮子文件的 mtime，不是子项的。源没了时叶子跳过，但虚拟外壳还在，
  进去是空的，`cherry show` 说哪几行读不到。
- 每一层虚拟目录都是一个 NFS 句柄和一条目录项；结构特别深的篮子会比平的篮子多一些
  lookup，但中间层不 stat、不 read_dir，换来的成本在配置规模下可以忽略。

## 备选方案

1. **路径在前 + 别名**（`/path alias`）——路径里可以有空格，分不清哪段是别名。弃。
2. **单独一行 `name` 再跟路径**——多一种状态，名字行和路径行可能对不上。弃。
3. **重名自动加后缀**——名字不可预测，页面和地址栏里会冒出没写过的名字。弃。
4. **直接共享整个父目录**——不需要选择，但会把没点名的东西也带出去。`/./` 就是为了只点名。

## 重新评估的触发条件

- 虚拟目录需要自己的 mtime（比如每个子项单独更新）→ 当前结构只由篮子文件决定，届时要
  重新考虑缓存语义。
- 真的出现平路径重名、且 `/./` 不合用 → 只给平的行加别名，不跟 `/./` 混。
