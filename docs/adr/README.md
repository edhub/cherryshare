## 术语

项目叫 **CherryShare**：CLI 是 `cherry`，服务是 `cherryd`。分享单位叫 **basket**，篮子里装的是 **cherry**。

- **basket** —— 用户创建的分享单位，就是数据目录里的一个 `<名字>.basket` 文件（ADR-0008）。创建者是其中所有内容的唯一源。它是一篮 cherry，不是目录：文件留在原处，basket 里只记录引用。
- **cherry** —— basket 文件里的一行：`可见路径 + 源路径`。没有 `/./` 时可见路径就是最后一段；带 `/./` 时保留后面的目录层级（ADR-0009）。可见路径在 basket 内唯一，且不能一条是另一条的前缀。
- **BasketLink** —— `{ host: Host, basket_id: [u8; 16] }`，host 可以是 IP 或主机名。内部文本形态是 `cherryshare:<host>:<32 位十六进制>`；`cherry list` 给用户的是 `http://<host>:20480/b/<id>/`。两者使用同一个凭证（ADR-0002）。
- **目录（listing）** —— **一个目录**的内容清单：`(名字, 种类, size, mtime, mode)`。由创建者现算，不递归。NFS 和网页列表共用这套逻辑（ADR-0002）。
- **服务** —— 读 `.basket` 文件、热加载并把它们讲成 NFS / HTTP 的常驻进程，同时提供 local socket、NFS（20490）和 HTTP（默认 20480）。可以由系统拉起，也可以前台运行。
- **管理客户端** —— 现在只有 CLI，通过 local socket 读服务（写是直接改文件）。接收者用浏览器看和下载，或用系统 NFS 客户端挂载；都不用安装 CherryShare。

## 刻意没有什么

以下都是讨论过并被明确否掉的，列在这里是为了防止将来被当成"顺手加一下"重新提出。

**因为 basket 只有一个源**（创建者不在线就不可用）

- 账号、登录、身份系统
- 成员表、成员发现、入群审批
- 做种 / 常驻缓存节点 / 可用性广播
- 跨 basket 内容去重、多源下载（多源 ≠ 多流）
- 中央服务器、中心目录、DHT（创建者本机的文件服务不在此列）

**因为不是多写者协作**

- `iroh-docs` / CRDT / gossip 广播树
- 目录的签名、版本号、本地缓存——目录是响应，不是制品

**因为自用、小范围、局域网是主路**

- 沙盒与 App Store 分发
- 离线可用性（"对方必须在线"是产品定位，不是缺陷）
- token 兑换层、次数预算、把限流当访问控制

**因为管理只在本地**（改数据目录里的文件，或走 local socket）

- 浏览器里的管理界面、通过 HTTP 创建或修改 basket
- 现有网页只供接收者浏览和下载；它与 NFS 共用 `basket_id`，不是管理入口（ADR-0004）。

**因为不需要**

- 扫描用的文件监听器——触发点就是请求本身。而且监听器本身不可信（停过、丢事件、网络卷），必须配周期重扫兜底，那照样得写扫描缓存，它只把延迟从几秒缩到毫秒；它唯一多买的是延迟，而 ADR-0001 担心的是**无界的**陈旧。
- 内容 store、内容寻址和 store 上的范围读取——创建者直接读源文件。NFS 的偏移读取与 HTTP Range 仍然支持（ADR-0007 决策六）。

**因为挂载走 NFS，网页走 HTTP**（ADR-0002、ADR-0007）

- 自研传输层（跨网那边也一样：加回一个现成的端口转发，不是自己写一套）
- SMB（它要凭证或访客配置，而 `basket_id` 已经是凭证）
- 缩短 `basket_id`——它要的是不可猜测性，不是唯一性
- **跨网**（现在不做）。将来要加的是**一个端口转发**，不是一套新的数据协议。

## 已推迟与当前限制

- **跨网**：当前不做。若以后需要，优先评估现成端口转发；NFS 和 HTTP 是两个端口，地址和链接也需要配套处理（ADR-0007 决策六）。
- **原生管理 GUI**：当前只有 CLI 管理，接收者网页已经实现。以后做管理 GUI 时按 ADR-0004 的原生 Rust 方案。
- **cherry 的别名、CLI JSON 输出**：当前都没有操作入口。`/./` 解决目录层级，但不换名字（ADR-0009 说明了别名为什么先不做）。basket 的名字就是文件名（改名就是改文件名），删文件和改 `id` 那一行就是删篮子、换凭证（ADR-0008）。
- **隐藏文件的过滤策略**：当前不跳过隐藏文件，包括 `.DS_Store`。网页另外保留了顶层 `_` 前缀，见 ADR-0002。
- **macOS 路径授权的提示名义**。（记在 ADR-0003）
- **NFS 参数可配置化**：当前固定 `actimeo=5`、端口 20490。端口绑定失败会记日志，NFS 不可用，但服务和其他入口继续运行（见 [`../errors.md`](../errors.md)）。
