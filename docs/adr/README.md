## 术语

- **tap** —— 用户创建的分享单位。创建者是其中所有内容的唯一源。它是一个条目列表，不是目录：文件留在原处，tap 里只记录引用。
- **条目（entry）** —— tap 里的一条记录：`名字 + 源路径 + 类型（文件 / 文件夹）`。名字在 tap 内唯一，默认取原文件名。
- **TapTicket** —— 分享用的那条链接：`{ addr: EndpointAddr, tap_id: [u8; 16] }`。
- **目录（listing）** —— 由条目展开出的内容清单：`(路径, hash, size, mtime)`，其中路径 = `条目名 + 条目内相对路径`。由创建者现算，不是制品。

## 已推迟

- **tap 的命名**（给 tap 起一个人可读的名字）。次要，暂不设计。
- **隐藏文件的默认处理**：创建者分享一个文件夹时，是否默认跳过以 `.` 开头的文件和目录（macOS 上任意文件夹都带 `.DS_Store`）。
